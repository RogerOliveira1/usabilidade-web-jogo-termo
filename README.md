# Jogo Termo

Atividade da disciplina **Usabilidade em Desenvolvimento Web, Mobile e Jogos**: desenvolver o jogo [Termo](https://termo.pt/) usando HTML, CSS e JavaScript.

**Jogar online:** https://rogeroliveira1.github.io/usabilidade-web-jogo-termo/

## Requisitos

- [x] Mínimo de 10 palavras distintas (o jogo tem 12)
- [x] Palavras com no mínimo 4 e no máximo 6 letras
- [x] 6 tentativas de acerto
- [x] Indica quando a letra está na posição incorreta (amarelo)
- [x] Indica quando a letra está na posição correta (verde)
- [x] Indica quando a letra não existe na palavra (cinza)
- [x] Indica quando o jogo acaba, por acerto ou por erro

## Como jogar

1. O jogo sorteia uma palavra. O número de casas mostra quantas letras ela tem.
2. Digite uma palavra com essa quantidade de letras e clique em **Enviar** (ou aperte Enter).
3. As cores mostram se cada letra está certa, em outra posição ou se não existe na palavra.
4. Você tem 6 tentativas. No fim, clique em **Jogar novamente** para sortear outra palavra.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: estilo e cores
- `script.js`: lista de palavras e lógica do jogo
